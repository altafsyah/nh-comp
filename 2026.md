## Priority 1: Performance & Scroll Jank Fixes

### 1.1 Remove/Reduce Blur Filter Animations (HIGH IMPACT) ⏳ NOT IMPLEMENTED

**Problem:** The `filter: blur()` CSS property is GPU-intensive and causes jank when many elements animate simultaneously.

**Current State:**
- `getSplitTextAnimation.tsx` applies blur to every word
- `fadeUpValue` constant uses blur
- Every section uses `whileInView` with blur transitions
- ~50+ elements animating blur simultaneously on scroll

**Files Affected:**
- `app/lib/getSplitTextAnimation.tsx`
- `app/constant/motion-value.ts`
- `app/routes/_index/route.tsx`
- `app/routes/_index/recent-work.tsx`
- `app/routes/_index/faqs.tsx`
- `app/components/footer.tsx`

**Solution:**
```tsx
// Before (expensive)
initial={{ opacity: 0, filter: "blur(4px)", y: 4 }}
animate={{ opacity: 1, filter: "blur(0px)", y: 0 }}

// After (performant - use transform and opacity only)
initial={{ opacity: 0, y: 8 }}
animate={{ opacity: 1, y: 0 }}
```

### 1.2 Reduce Animation Complexity ⏳ NOT IMPLEMENTED

**Problem:** `getSplitTextAnimation` creates individual `<span>` elements for every word with staggered animations.

**Example:** "We're here to help you solve your biggest challenges with smart, effective software." = 13 animated elements with 13 different delays.

**Solution:**
- Use CSS `clip-path` or single-element text reveal
- Or animate lines instead of words
- Consider removing text animations on mobile

### 1.3 Optimize whileInView Usage ✅ COMPLETED

**Problem:** Too many elements with `whileInView` cause multiple Intersection Observer callbacks.

**Solution:**
- Add `viewport={{ once: true, margin: "-100px" }}` to trigger earlier
- Batch animations per section instead of per element
- Use `layout` prop sparingly

### 1.5 Image Optimization ✅ COMPLETED

**Problems:**
- JFIF images are not web-optimized
- No lazy loading
- No explicit dimensions (causes CLS)
- No responsive images

**Current Images:**
- `work_dummy_1.jfif`, `work_dummy_2.jfif`, `work_dummy_11.jfif`
- `dummy_1-4.jfif`, `hero_1-2.jfif`

**Solutions:**
1. Convert JFIF to WebP (50-80% smaller)
2. Add `loading="lazy"` attribute
3. Add explicit `width` and `height` attributes
4. Use `srcset` for responsive images

```tsx
// Before
<img src={item.imageUrl} alt={item.title} className="object-cover w-full h-full" />

// After
<img
  src={item.imageUrl}
  alt={item.title}
  loading="lazy"
  width={800}
  height={600}
  className="object-cover w-full h-full"
/>
```

### 1.6 Fix Lenis + Motion Conflict ✅ COMPLETED

**Problem:** Lenis hijacks scroll events which can conflict with Motion's scroll-triggered animations.

**Solution in `app/root.tsx`:**
```tsx
<ReactLenis
  root
  options={{
    lerp: 0.1,
    smoothWheel: true,
    syncTouch: false, // Disable on touch devices
  }}
/>
```

### 1.7 Reduce Backdrop Blur ✅ COMPLETED

**Problem:** `backdrop-blur` is expensive, especially on mobile.

**Files using it:**
- Hero section cards
- Services cards
- Footer CTA section

**Solution:** Use solid colors or reduce blur radius on mobile:
```css
@media (max-width: 768px) {
  .backdrop-blur { backdrop-filter: none; }
}
```
